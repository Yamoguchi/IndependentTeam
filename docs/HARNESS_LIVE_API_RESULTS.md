# Прогоны через API

Штатная конфигурация использовала `qwen3.8-27b-noreason`, одну сессию, `B+C+D`, локальную маршрутизацию, планировщик F, ранний отказ и прямую публикацию подтверждённых ответов.

| Набор и конфигурация | Прошли локальную проверку | Баллы | Вызовы API | Расход в выходном эквиваленте | Время агента |
| --- | ---: | ---: | ---: | ---: | ---: |
| 8 публичных задач, baseline | 8/8 | 20/20 | 27 | 4 319,6 | 88,302 с |
| 8 публичных задач, штатная | 8/8 | 20/20 | 24 | 3 822,3 | 78,896 с |
| 100 задач, исторический baseline | 100/100 | 242/242 | 342 | 50 861,7 | 1 302,068 с |
| 100 задач, штатная | 96/100 | 233/242 | 321 | 50 328,1 | 1 129,255 с |

В парном прогоне восьми задач локальный лимит составил 7 500 на режим. Штатная конфигурация сохранила все баллы и снизила расход на 11,51%. SHA-256 очищенных входов — `d4bb7e3cd5364f1321174a4aa97de462250d3ffe2b066b0ecf912c794e00ebbe`.

На 100 задачах локальный лимит составил 50 861,7. Все задачи дошли до API, 98 ответов были опубликованы. Два ответа по математике не прошли проверку, для двух задач поиска не хватило остатка на резерв следующего запроса. Исторический и новый прогоны имеют одинаковый SHA-256 очищенных входов `bae62b0a9b0b58a3a961ed6ba17ac3fdbe961f676d9776cec2ce1825554c316f`. Исторический прогон выполнен в Docker, новый — нативно.

На 96 задачах, которые оба режима решили правильно, расход вырос с 48 191,4 до 48 885,2. В категории анализа данных все 15 дополнительных вызовов пришлись на 19 задач с ошибкой `run_python`. На остальных шести расход изменился на 1,4. Все 25 задач с кодом прошли проверку и получили прямую публикацию после успешных тестов. Маршрут LOCAL в этом наборе не выбрал ни одной задачи.

Полные трассы и независимые оценки сохранены в локальных каталогах `logs/experiments/live-api-public.AJqxvR` и `logs/experiments/live-api-100.bK5IrQ`. Оба набора проверены локально. Оценка по скрытым тестам остаётся за жюри.

## Воспроизведение прогона на 100 задачах

Из корня проекта с настроенными `LLM_BASE_URL` и `LLM_API_KEY` подготовьте новую копию задач. Стенд отделит поля локальной проверки от входов агента.

```bash
RUN_DIR=$(.venv/bin/python benchmark.py prepare --source-dir "$PWD/task-dir")
.venv/bin/python benchmark.py run --run-dir "$RUN_DIR" \
  --proxy-kind organizer --local-budget 50861.7 --timeout 3590 --run-timeout 3500 \
  --mode B+C+D --routing --planner F --early-stop --direct-publish
.venv/bin/python benchmark.py check --source-dir "$PWD/task-dir" --run-dir "$RUN_DIR"
```
